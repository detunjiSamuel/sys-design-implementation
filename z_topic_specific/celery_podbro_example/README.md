# Celery Podbro Example

This is a simple Django project that uses Celery. I created this because I had to prep for something and needed to remember Django.

## Setup

Because this project uses a submodule, make sure to initialize and update it:

```bash
git submodule update --init --recursive
```

Then, install the dependencies using `uv`:

```bash
uv pip install -e ./podbro
```
