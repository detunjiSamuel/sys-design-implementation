# Market Feed

A learning project. Built this while preparing for a situation that required deep knowledge of real-time trading systems.

## What it is

A simulated real-time market data feed using Django, Celery, Kafka, and Redis. Covers things like live price streaming, price alerts, and market sentiment analysis.

## Stack

- Django
- Celery
- Kafka
- Redis
- Docker

## Goal

Just to learn. Not production code.
